# MORGELON — Premium Game Design

Fiction. Prosthetics only for production. Not medical advice.

## Product fantasy

A premium **Colorado body-horror extraction thriller**: you itch, you pull, it feels too good, the mountain agrees with you, and every perfect shot finishes the graft.

Tone: boutique horror — The Fly intimacy × RE spatial dread × Dr. Pimple Popper satisfying disgust × high-country sublime.

## Pillars (ship checklist)

| Pillar | Premium bar |
| --- | --- |
| **Itch** | Persistent audio/visual itch bed; never fully clearable |
| **Extract** | Hold-to-pull macro minigame; relief SFX; second thread always appears |
| **Hallucinate** | Bloom thresholds unlock vein-worms → sleep-trees → web shoots |
| **Consensus** | Elevation / party size removes dialogue choices |
| **Gaze** | Keeping GOLD footage = Evidence + Bloom; delete = safer, poorer |

## Core loop (60-second fantasy)

1. Enter zone (valley → switchbacks → clone stand → overlook → core)  
2. Manage itch (scratch = micro Bloom)  
3. Optional **Extract** for Evidence (Popper macro)  
4. Survive Joined consensus pulse  
5. Sleep / rest → mandatory hallucination beat if Bloom high  
6. Choose: keep GOLD card or delete  

## Systems (premium v1)

### Bloom (0–100)
- +2 scratch, +7 extract, +3 photo, +5 sleep-with-high-bloom, +4 overlook tourism  
- 40+: “second thread” VFX  
- 70+: hallucination overlays  
- 90+: Consensus locks most dissent options  

### Evidence / Power
- Extracts and GOLD clips feed Evidence  
- Ending A: Evidence ≥ 6 and Bloom < 60 → believed, alone  
- Ending B: Bloom ≥ 80 → Joined summit (calm smile)  
- Ending C: delete all GOLD, Evidence < 3 → clinic denial loop  

### Extract minigame
- Hold to draw filament; release early = fail itch spike  
- Perfect pull = Evidence + satisfaction sting + forced spawn  

### Joined AI
- Idle sway on metronome  
- Pulse: synchronized approach  
- Desync by burning fruiting prop / leaving clone stand
